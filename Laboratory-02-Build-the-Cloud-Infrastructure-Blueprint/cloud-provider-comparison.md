# Cloud Provider Comparison

## Infrastructure Service Comparison

| Infrastructure Component       | AWS        | Microsoft Azure        | Google Cloud Platform       |
| ------------------------------ | ---------- | ---------------------- | --------------------------- |
| Compute                        | Amazon EC2 | Azure Virtual Machines | Compute Engine              |
| Storage                        | Amazon S3  | Azure Blob Storage     | Cloud Storage               |
| Networking                     | Amazon VPC | Azure Virtual Network  | Virtual Private Cloud (VPC) |
| Identity and Access Management | AWS IAM    | Microsoft Entra ID     | Cloud IAM                   |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

Based on what I researched, I think **AWS** offers the broadest range of cloud services. It has many different services for computing, storage, databases, networking, security, and other cloud needs. I also noticed that AWS has a lot of options, so organizations can choose the services that fit their needs.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend **Microsoft Azure** because it works well with Microsoft products and services. If an organization is already using Microsoft technologies, Azure can make it easier for them to connect their existing systems to the cloud. I think this would be a good choice because they would already be familiar with many Microsoft tools.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

I would choose **Google Cloud** because it is well known for its Artificial Intelligence, Machine Learning, and Kubernetes services. From my research, I learned that Google Cloud provides different tools that developers can use to create, deploy, and manage applications. This makes it a good platform for organizations that are interested in AI and modern cloud technologies.

### 4. What similarities did you observe among the three cloud providers?

One thing I noticed is that **AWS, Microsoft Azure, and Google Cloud** offer many similar services. All three provide computing, storage, networking, databases, and security or identity services. The main difference I noticed is that they use different names and have different ways of providing these services. Even though the names are different, their main purpose is still to help organizations build and manage applications in the cloud.
