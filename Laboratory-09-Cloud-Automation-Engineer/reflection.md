# Mission Reflection

This laboratory activity helped me understand how automation can make cloud administration more efficient. Instead of manually creating backups, I learned how to write a Bash script that creates a backup directory and compresses application data into a timestamped archive. I also learned that the `chmod +x` command allows a script to be executed directly when the required permissions are available.

Automation is important when managing hundreds of cloud servers because repeating the same task manually takes time and increases the chance of human error. A scheduled script can perform routine tasks consistently. However, automation also has risks. A destructive command or an incorrect file path could damage important data or affect many servers if the script is deployed widely. This is why scripts should be reviewed and tested in a safe environment before they are scheduled or deployed.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash uses commands and variables to perform operations step by step. Docker Compose uses YAML configuration to describe services and how containers should run. Both help reduce manual work, but they solve different problems.

Across Laboratories 1 to 9, my understanding of cloud computing developed from learning basic cloud concepts to exploring infrastructure, cloud services, containers, data, deployment, operations, security, and automation. I learned that cloud computing involves more than launching servers. It also requires monitoring, protecting resources, organizing data, and making operations reliable.
