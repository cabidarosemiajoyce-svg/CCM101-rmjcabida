## Mission Overview
This laboratory focuses on securing a Linux server using the UFW firewall and controlling network traffic through firewall rules.

## Objectives
- Understand the Principle of Least Privilege.
- Understand the attack surface of a server.
- Configure a Default Deny firewall policy.
- Allow SSH and TCP port 8080.
- Document firewall commands and security practices.
