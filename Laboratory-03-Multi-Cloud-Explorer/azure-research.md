# Microsoft Azure

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services that organizations can use to run applications, store data, connect systems, manage identities, and build modern cloud solutions. Azure supports both Windows and Linux workloads and is widely used by organizations that already work with Microsoft technologies.

## Global Infrastructure

Azure uses a global infrastructure made up of regions and data centers located around the world. This allows organizations to select locations based on factors such as user proximity, availability, and data residency requirements.

Azure's global infrastructure is especially useful for organizations that operate across different countries because applications can be deployed in locations that are appropriate for their users and business requirements.

## Cloud Management Console

The Azure portal is a web-based management interface for Azure resources. Administrators can use the portal to create virtual machines, configure storage and networking, manage identities, monitor resources, and manage other Azure services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide on-demand virtual computers in the cloud. They can run Windows or Linux operating systems and are useful when an organization needs control over the computing environment.

### 2. Azure Blob Storage

Azure Blob Storage is Microsoft's object storage service. It is designed for storing large amounts of unstructured data such as documents, images, videos, backups, and other files.

### 3. Azure Virtual Network

Azure Virtual Network provides networking capabilities for Azure resources. It allows organizations to create private network environments and control how their cloud resources communicate.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users, applications, devices, and access to resources.

## Three Advantages

### 1. Strong Microsoft Integration

Azure works closely with Microsoft's existing technologies and services. This makes it a practical option for organizations that already use products such as Windows Server and Microsoft 365.

### 2. Enterprise and Hybrid Cloud Support

Azure provides services that can support organizations with both cloud and existing on-premises infrastructure.

### 3. Wide Range of Services

Azure provides services for computing, storage, networking, identity, databases, AI, security, and many other IT requirements.

## Typical Enterprise Use Cases

Azure is commonly suitable for organizations with Microsoft-based environments. A company can use Azure Virtual Machines to run Windows or Linux workloads, Azure Storage for business data and backups, and Microsoft Entra ID to manage identities and access. Universities, government organizations, and enterprises can also use Azure when they need to connect existing infrastructure with cloud services.
