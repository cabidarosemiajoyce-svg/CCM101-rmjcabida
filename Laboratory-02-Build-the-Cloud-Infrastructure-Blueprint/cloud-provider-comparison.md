# Cloud Provider Comparison

## Infrastructure Service Comparison

| Infrastructure Component       | AWS        | Microsoft Azure        | Google Cloud Platform       |
| ------------------------------ | ---------- | ---------------------- | --------------------------- |
| Compute                        | Amazon EC2 | Azure Virtual Machines | Compute Engine              |
| Storage                        | Amazon S3  | Azure Blob Storage     | Cloud Storage               |
| Networking                     | Amazon VPC | Azure Virtual Network  | Virtual Private Cloud (VPC) |
| Identity and Access Management | AWS IAM    | Microsoft Entra ID     | Cloud IAM                   |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

Based on my research, AWS offers a very wide range of cloud services. It has services for computing, storage, networking, databases, security, and many other cloud needs.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works well with Microsoft products and services. This can make it easier for an organization that already uses Microsoft technologies to move to and manage cloud services.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud is well known for its Artificial Intelligence, Machine Learning, and Kubernetes services. It provides tools that can help developers build, deploy, and manage modern cloud applications.

### 4. What similarities did you observe among the three cloud providers?

I noticed that AWS, Microsoft Azure, and Google Cloud provide many of the same basic cloud services. All three offer compute, storage, networking, and identity management. However, they use different names and approaches for their services.
