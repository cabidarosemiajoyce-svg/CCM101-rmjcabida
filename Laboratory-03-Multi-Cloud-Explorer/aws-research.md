# Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides organizations with computing power, storage, networking, databases, security, and many other services through the internet. Instead of buying and maintaining all of the physical hardware themselves, organizations can use AWS resources when they need them and scale them according to their workload.

## Global Infrastructure

AWS organizes its infrastructure into geographic Regions and Availability Zones. A Region is a separate geographic area, while Availability Zones are isolated locations within a Region. This structure allows organizations to place their applications closer to users and design systems that can continue operating even when a problem affects one location.

For example, an organization serving users in different countries can choose appropriate AWS Regions and distribute its workloads across multiple Availability Zones. This can help improve availability and reduce network latency.

## Cloud Management Console

The AWS Management Console is a web-based interface used to manage AWS resources. Through the console, administrators can create and configure services, monitor resources, manage security permissions, and control their cloud environment without having to perform every task through command-line tools.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and other workloads. It allows organizations to choose computing resources based on the requirements of their applications.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service. It can be used to store files, backups, application data, images, videos, and other types of information.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides a logically isolated virtual network for AWS resources. It allows administrators to control networking components such as IP ranges, subnets, routing, and connectivity.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls who can access AWS resources and what actions they are allowed to perform. It helps administrators manage users, roles, and permissions.

## Three Advantages

### 1. Wide Range of Services

AWS provides services for many different IT requirements, including computing, storage, networking, databases, security, analytics, and application development.

### 2. Scalability

AWS allows organizations to increase or decrease resources based on demand. This is useful when an application experiences changes in workload or user traffic.

### 3. Global Infrastructure

AWS provides Regions and Availability Zones in different parts of the world. Organizations can use this infrastructure to build applications that are designed for availability and users in different locations.

## Typical Enterprise Use Cases

AWS can be used by businesses for many types of workloads. E-commerce companies can use AWS to host websites and applications that need to handle changing levels of traffic. Media companies can use storage and content delivery services for large amounts of digital content. Enterprises can also use AWS for application migration, backup, disaster recovery, and other infrastructure requirements.
