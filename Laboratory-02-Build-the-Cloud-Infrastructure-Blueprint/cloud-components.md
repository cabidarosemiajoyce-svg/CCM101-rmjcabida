# Cloud Infrastructure Components

## Compute Resources

### Purpose

Compute resources provide the processing power needed to run applications, commands, and services on a cloud server.

### Why It Is Important

Compute resources are important because they allow the server to process tasks and run applications properly.

### Relation to the Linux Environment Provided by KillerCoda

In my KillerCoda Linux environment, I checked the CPU, CPU cores, and RAM. This helped me understand how the Linux server uses its compute resources to process commands and run different tasks.

## Storage Resources

### Purpose

Storage resources are used to save files, system data, applications, and other information on the server.

### Why It Is Important

Storage is important because cloud applications and systems need a place to store and access their data.

### Relation to the Linux Environment Provided by KillerCoda

In my KillerCoda Linux environment, I checked the available disk space and mounted file systems using `df -h` and `findmnt`. This helped me understand how storage is organized and used by the Linux server.

## Networking Resources

### Purpose

Networking allows the server, users, and other services to communicate with each other.

### Why It Is Important

Networking is important because cloud resources need a network connection to communicate and access different services.

### Relation to the Linux Environment Provided by KillerCoda

In my KillerCoda Linux environment, I checked the server's IP address using the `hostname -I` command. This helped me understand how the Linux server connects to and communicates through a network.

## Operating System

### Purpose

The operating system manages the server's hardware and provides the environment needed to run applications and commands.

### Why It Is Important

An operating system is important because it manages the server's resources and allows different workloads and applications to run.

### Relation to the Linux Environment Provided by KillerCoda

The KillerCoda environment provided me with a Linux operating system where I could use the terminal and different Linux commands. I used it to investigate the server's hardware, storage, networking, and other system information.
