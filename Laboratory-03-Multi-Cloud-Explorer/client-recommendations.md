# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a good choice for the startup because the company has a limited budget but expects its application to grow. The startup can begin with the resources required for its current workload and increase capacity as the number of users increases. AWS also provides services covering computing, storage, and databases, which are important for a mobile application.

### Possible Services

- Amazon EC2
- Amazon S3
- Amazon RDS

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Moving selected services to Azure can provide a more familiar Microsoft-based environment. Azure also provides identity and virtual machine services that can work with the university's existing technology.

### Possible Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Blob Storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

GCP is a strong choice for the AI research company because its services and infrastructure support artificial intelligence, machine learning, and high-performance workloads. The company can use Compute Engine for computing resources and Vertex AI for AI and machine learning development. GKE can also be used when the research applications need container orchestration.

### Possible Services

- Compute Engine
- Vertex AI
- Google Kubernetes Engine (GKE)

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a suitable choice for a global e-commerce company because the business needs infrastructure that can handle changing traffic and remain highly available. Compute resources can be scaled as demand changes, while load balancing can distribute traffic across application resources. Storage services can also support product data, files, and other application content.

### Possible Services

- Amazon EC2
- Elastic Load Balancing
- Amazon S3

---

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad services and scalable infrastructure |
| Enterprise Organization | AWS | Large service portfolio and enterprise capabilities |
| Microsoft Environment | Azure | Strong Microsoft integration |
| AI / Machine Learning | GCP | Strong AI and machine learning capabilities |
| Kubernetes Deployment | GCP | Strong managed Kubernetes capabilities |
| Global Web Application | AWS | Global infrastructure and scalable services |
