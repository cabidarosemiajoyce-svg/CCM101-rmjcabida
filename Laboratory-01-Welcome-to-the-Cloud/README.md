## Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a Linux environment and the basic tasks that a cloud engineer needs to know. I used KillerCoda to work with Linux and GitHub to create my Cloud Computing portfolio.

## Objectives

- Access a Linux environment using KillerCoda.
- Explore and navigate Linux.
- Check basic system information.
- Create and organize files and folders.
- Create a GitHub repository.
- Document my work using Markdown.

## Activities Performed

- Accessed Ubuntu through KillerCoda.
- Created and logged in to the user account rmjcabida.

- Gathered information about the Linux system.
- Created folders and Markdown files.
- Created and organized my GitHub Cloud Computing portfolio.
