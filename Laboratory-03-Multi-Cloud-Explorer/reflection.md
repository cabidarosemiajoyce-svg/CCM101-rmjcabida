# Mission 3 Reflection

This mission helped me understand how AWS, Microsoft Azure, and Google Cloud Platform provide similar cloud services while having different strengths. The platform that impressed me the most was AWS because it provides a wide range of services that can support different types of workloads. While researching the three providers, I realized that cloud computing is not limited to simply renting virtual machines. It also includes storage, networking, identity management, databases, containers, and many other services.

AWS, Azure, and GCP have several similarities. All three provide virtual machines, object storage, networking, identity and access management, databases, and Kubernetes services. They also have global infrastructure that allows organizations to deploy workloads in different locations.

Business requirements have a major effect on cloud platform selection. A university that already uses Windows Server, Microsoft 365, and Active Directory may benefit from Azure because of its Microsoft integration. An AI research company may prefer Google Cloud because of its AI, machine learning, and Kubernetes capabilities. A startup may focus more on scalability, available services, and managing its resources efficiently.

Acting as a Cloud Solutions Consultant taught me that there is no single cloud provider that is best for every organization. The correct choice depends on the customer's existing technology, budget, workload, scalability requirements, and business goals. I also learned how to match equivalent services between different cloud providers.

My GitHub Cloud Computing Portfolio improved because I added organized research documents, comparison tables, recommendations, screenshots, and a reflection. I also practiced using Markdown and maintaining a meaningful commit history. Overall, this mission helped me understand how technical cloud decisions should be connected to actual business requirements.
