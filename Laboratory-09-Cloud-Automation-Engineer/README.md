# Laboratory Activity 9: The Cloud Automation Engineer

## Mission Overview
This activity focuses on automating cloud administration tasks using Bash scripting and Cron. The main task is to create a script that compresses application data into a backup file and configure a schedule to run it automatically.

## Objectives
- Understand Bash scripts and variables.
- Create and execute a backup script.
- Use `chmod` to modify file permissions.
- Configure a Cron job to run a script automatically.
- Document the process and results.

## Commands Executed
- `mkdir`
- `echo`
- `nano`
- `chmod +x`
- `tar -czf`
- `ls -l`
- `crontab -l`
- `crontab -e`

## Skills Learned
- Bash scripting
- Linux file permissions
- File compression and backups
- Cron scheduling
- Technical documentation using Markdown
